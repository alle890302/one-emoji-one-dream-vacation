One emoji for a dream vacation, written by a tiny Python program for
make.fun's "One Emoji, One Dream Vacation" bounty.

The entry is 🗻 — Mount Fuji: one named, iconic place, a postcard at a
glance, one particular dream trip rather than any holiday.

## How it works

`main.py` writes the single emoji to `/output/entry.txt`, deterministically,
with no trailing newline.
